# 云游中国：旅游景区交互地图

基于 Vue 3、MapLibre GL JS 与 OpenFreeMap 矢量底图构建的中国大陆旅游景区地图。页面沿用实验二的静态网页结构，不需要打包工具即可运行。

## 功能

- 收录中国大陆代表性博物馆、历史名迹、公园自然、商业街区和主题乐园
- 按景点名称、城市、省份、分类或关键词模糊搜索并飞行动画定位
- 鼠标悬浮景点标记时展示介绍、评分、亮点和建议游览时间
- 按类别筛选地图标记，支持热门景点快速定位
- 使用 OpenFreeMap 矢量地图，缩放时文字与道路保持清晰，最大支持 18 级缩放
- 定位导航：从当前位置、地图选点或另一景点出发，规划到目标景点的驾车 / 骑行路线（基于 OSRM），展示总距离、预计用时与分段转向指引
- 账号系统：用户可注册、登录；登录后可为景点点赞收藏，并在个人主页查看 / 取消收藏
- 管理后台：使用指定管理员账号登录后，可新增、编辑、删除景点，或一键恢复默认数据
- 桌面端三栏数据面板与移动端自适应布局

## 运行

在当前目录启动静态服务器：

```powershell
python -m http.server 8000
```

浏览器访问 `http://localhost:8000/index.htm`。Vue 与 MapLibre 已保存在本地；OpenFreeMap 矢量地图数据与 OSRM 路线服务仍需联网加载。

## 账号系统

账号、收藏与景点数据均保存在浏览器 `localStorage` 中（纯前端方案，无需后端），首次运行会自动初始化默认景点与管理员账号。

- **注册 / 登录**：点击顶栏「登录」按钮，切换「注册」标签创建账号，登录后顶栏显示头像昵称。
- **收藏**：登录后，在景点详情卡点击「收藏」，或在个人主页取消收藏；个人主页汇总展示所有已收藏景点。
- **管理员**：演示管理员账号为 `admin`，密码 `admin123`。登录后顶栏出现「⚙ 管理」按钮，可新增 / 编辑 / 删除景点，或「恢复默认」数据。

> 说明：密码经简单散列后存储，仅用于课程演示，不具备生产级安全性。

## 扩展数据

在 `js/attractions.js` 的 `window.CHINA_ATTRACTIONS` 数组中添加对象即可新增默认景点。每条数据包括名称、城市、省份、分类、WGS84 经纬度、评分、简介、亮点和建议游览时间。首次加载后景点数据会写入 `localStorage`，之后的增删改以本地存储为准；如需让静态数据改动生效，请清除站点数据或使用管理后台的「恢复默认」。
